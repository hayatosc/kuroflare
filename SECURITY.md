# Security Policy

Do not open a public issue for a suspected vulnerability that could expose
vault contents, credentials, tokens, deployment hooks, or account resources.

Report security issues through GitHub's private vulnerability reporting for
this repository. Include the affected version, reproduction steps, expected
impact, and whether any secret may have been exposed. Revoke exposed secrets
before submitting the report.

Only the latest published Kuroflare release is eligible for security fixes
during the initial preview period.
